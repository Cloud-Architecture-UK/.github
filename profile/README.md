**Practical notes on _Azure_ and _Microsoft 365_.**

In-depth guides, field notes and exam prep for admins, engineers and architects.

Cloud Architecture is my blog on Azure and Microsoft 365, covering both platforms end to end.

It's launching soon at [www.cloud-architecture.co.uk](https://www.cloud-architecture.co.uk/).

### What's coming

- **In-depth guides.** One topic covered start to finish, with the decisions, the steps and the code.
- **Field notes.** Shorter write-ups of what I've hit in real tenants and subscriptions.
- **Exam prep.** Study series for the Microsoft certifications.
- **Retirement radar.** A running list of Azure and Microsoft 365 retirements and changes.
- **Scripts and templates.** The code behind the posts, free to read and fork.

### The Microsoft 365 toolkit

I'm also building a toolkit to stand up a Microsoft 365 tenant from scratch and run it for its whole life. It has four pillars:

- **Provision.** Create the tenant from a definition file, so every tenant is built the same way.
- **Configure.** Set up every product, from Exchange and Teams to Purview and Copilot.
- **Secure.** Harden it to well-known security standards, mapped control by control.
- **Operate.** Posture reporting, drift detection and lifecycle.

It's private while I finish and test it.
